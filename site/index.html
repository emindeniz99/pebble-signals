signal-piu

Fine-grained reactive UI — Solid-style signals + JSX, no VDOM — for Pebble watches on Moddable XS/Piu. Every watch below is a REAL example running the SHIPPED runtime in your browser: no SDK, no emulator, no install.

Click a watch to focus it, then drive it: ↑ up · ↓ down · Enter select · Backspace back.

pulse — the flagship face

A live clock, a per-second pulse dot, and three accent themes on up/down (persisted to flash). The one composition that runs every proven mechanism at real arena pressure.

counter — the classic

up = +1, down = -1. One useState, one bound Label, and no VDOM diff anywhere: the signal writes the Label's string directly.

menu — a driven list

The app owns the selected index; Menu highlights that row and scrolls to keep it inside the viewport. up/down wrap.

sectionlist — grouped rows

Three sections in one recycled five-slot window. Headers are never selectable, so stepping walks row-to-row ACROSS sections and the list scrolls past each boundary.

card — a reactive title bar

Two titled boxes. The second card's title is a thunk, so up/down repaint the title bar with zero bind wiring at the call site.

What this is not

Layout here is APPROXIMATE: Piu's layout engine is not reimplemented, only DOM-rendering stubs stand in for it. The preview bundles the raw .tsx, so the auto-thunk lowering pass never runs (bare reactive props stay static — these examples write thunks). Lazy modules (importNow), bitmaps, the Canvas Port and the host clock global are not stubbed, which is why the draw-based ultraface and the phone-data weather face are not in this gallery. QEMU stays the truth: pnpm run dev -- --app pulse.
